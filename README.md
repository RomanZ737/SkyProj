# Виджет банковских операций клиента
Проект домашней работы по созданию **виджета банковских операций клиента**
На данный момент в проекте существуют модули masks, processing, widget.

Модуль **masks** содержит функции:
* get_mask_card_number - *Принимает номер карты в виде числа или строки и возвращает маску номера по правилу XXXX XX-- ---- XXXX*
* get_mask_account - *Принимает номер счета в виде числа или строки и возвращает маску номера по правилу --XXXX*

Модуль **widget** содержит функции:
* mask_account_card - *Принимает строку, содержащую тип и номер карты или счета,
    возвращает строку с замаскированным номером*
* get_date - *Принимает дату в формате ISO-8601, возвращает дату в стандартном формате: ДД.ММ.ГГГГ*

Модуль **processing** содержит функции:
* filter_by_state - *Принимает список словарей и опционально значение для ключа
    state. Возвращает новый список словарей, содержащий только те словари,
    у которых ключ state соответствует указанному значению*
* sort_by_date - *Принимает список словарей и необязательный параметр, задающий порядок
    сортировки (по умолчанию — убывание). Возвращает новый список,
    отсортированный по дате (date).*

Модуль **generators** содержит функции:
* filter_by_currency - *Принимает на вход список словарей, представляющих транзакции.
    Функция (генератор) возвращает итератор, который поочередно выдает транзакции,
    где валюта операции соответствует заданной (например, USD)*
* transaction_descriptions - *Принимает список словарей с транзакциями и возвращает описание
    каждой операции по очереди*
* card_number_generator - *Принимает начальное и конечное значения для генерации диапазона номеров.
    Возвращает номера банковских карт в формате XXXX XXXX XXXX XXXX,
    где X — цифра номера карты*

**Тестирование**
Пакет *tests* на данный момент включает тестирование модулей: *masks*, *widget*, *processing*, *generators*.
Модули протестированы на предмет подачи на вход различного формата данных, "пустых данных", а также 
не корректного формата данных и на предмет граничных значений.
Все модули в пакете *src* охвачены тестированием на 100%.
